# Demo script (2 minutes)

**0:00–0:15 · Product framing**
"PARALLAX is incident intelligence for distributed systems. It helps a team move from noisy telemetry to a defensible recovery decision."

**0:15–0:35 · Impact**
Open the command center. Show the critical incident, impacted checkout path and degraded Stock Engine. Click nodes in the service map.

**0:35–1:00 · Competing hypotheses**
Explain H-01, H-02 and H-03. Point to the counter-evidence that weakens the slow-query and payment hypotheses. Explain that scores are heuristic evidence scores, not calibrated probabilities.

**1:00–1:20 · Counterfactual**
Run the bounded pool-capacity simulation. Show before/after metrics and say explicitly that the experiment is simulated and does not touch production.

**1:20–1:40 · Human decision**
Approve or reject with a note. Explain that PARALLAX records the decision but does not execute a production change.

**1:40–2:00 · Artifact**
Export the Markdown report. If Switch is configured, show the actual watcher → investigator handoff and human decision in the shared room. Do not claim a live Switch run unless captured.
