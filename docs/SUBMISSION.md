# Hackathon submission draft

## Project
PARALLAX — Evidence-led incident intelligence for distributed systems.

## Track
Best Business Workflow.

## Description
PARALLAX helps engineering teams investigate distributed-system incidents through a shared, evidence-led workflow. It maps service impact, compares competing root-cause hypotheses with supporting and contradicting evidence, runs a controlled counterfactual simulation, and prepares a risk-aware recovery proposal. A human operator explicitly approves or rejects the proposal, with the decision preserved in an incident report.

The Switch workflow is designed around two collaborating agents: a watcher that raises the incident and an investigator that owns the evidence review. Their work is coordinated in a shared room so the team can see the handoff, challenge the findings and make the final decision together.

## Be accurate before submitting
Only claim the Switch workflow as implemented after both agent sessions are live and a complete cross-agent handoff has been recorded. If the template has not been run, describe it as the integration design, not a completed integration.

Only claim telemetry collection from OpenTelemetry/Prometheus/Jaeger if those systems are actually deployed and instrumented. This repository's current demo uses deterministic simulated telemetry.
